About Me

I am Muhammad Usman, a Full Stack Developer & Programmer focused on building modern, responsive and functional web applications. My development experience covers both frontend and backend technologies, allowing me to work across different parts of a complete web application.

On the frontend, I work with HTML, CSS, JavaScript and React to create structured, interactive and responsive interfaces. I focus on clean layouts, useful interactions, responsive design and a smooth experience across different screen sizes.

On the backend, I work with Python and Node.js and understand how frontend applications communicate with backend systems through REST APIs. I can work with databases and connect application logic with stored data to create complete full stack solutions.

My development work also includes database technologies such as MySQL, MongoDB and MariaDB. I use Git and GitHub for version control and code management, while VS Code, BlueJ and Dev C++ are among the development environments I use for programming.

I also work with deployment platforms such as Vercel and Netlify. This allows me to take applications from development to deployment and make them accessible online. I also work with modern technologies such as Next.js, AI based tools and prompt engineering techniques.

My approach to development is based on writing organized code, understanding how different technologies work together and building applications that are practical, responsive and maintainable.
